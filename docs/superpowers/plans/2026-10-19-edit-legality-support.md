# 编辑合法化覆盖扩展

目标：第三、第四世代编辑值优先；自动维护 PID、经验、等级和同游戏相遇背景，尽可能找到完整合法结果，不以改掉 IV、EV、性格、性别、闪光、实际特性或招式通过检查。

1. 用报告中的小拉达两项 IV31、迷你龙六项 IV31建立失败用例。复用 PKHeX 相遇生成器验证孵化及其他来源候选，禁止修改来源实体。
2. 新增编辑专用修复入口：先调用保留来源修复，再搜索官方同游戏模板；复制必要后台字段，保留用户属性与训练家，最小必要经验/等级调整，最终完整校验。原保真/传送用途不改变语义。
3. 编辑预览和所有编辑保存使用同一入口；清楚展示 PID、捕获/孵化来源、等级、经验、球和标记等后台调整。确认前不写入。
4. 新增可运行验证矩阵：Gen3/Gen4、迁移、野生/静态/孵化/NPC、不同性别/特性/性格/闪光、IV/EV/等级/招式/蛋状态及进化种类。对可构造的合法组合要求修复成功；冲突要求精确拒绝且字节不变；统计覆盖与运行耗时。
5. 检查保存回读、备份、取消与模拟器小拉达/迷你龙现场，完成全量回归与严格 Android 构建。记录支持边界，不把未穷尽搜索称为绝对无解。

涉及：LocalRepository 编辑修复与保存，EditCopyActivity 预览，MainActivity 编辑保存；Verifier 新增覆盖矩阵及入口。复用现有私有存档，测试产物仍放忽略目录。
